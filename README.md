# discourse-kuu-points

京大中文论坛（KUU）的经验值和鲸币插件。

- **等级**：1–5 级，每 200 经验升一级，5 级封顶
- **每日任务**（日本时间 0 点分界）：签到、第一个新话题、第一次回复、第一次给别人点赞、第一次转发，每项每天奖励一次
- **鲸币商城**（`/kuu-shop`）：等级和经验进度、鲸币余额、今日任务和签到、用鲸币兑换头像框 / 饰品、佩戴和取下、明细
- **等级标签和头像装饰**：帖子、用户卡片、个人主页
- **管理后台**（后台 › 插件 › 经验值和鲸币）：商品管理（新增、编辑、上下架、图片上传）、手动加减经验 / 鲸币（必须填原因，用户在明细里能看到，记进管理员操作日志）

站点设置 `kuu_points_enabled` 默认关闭。

## 接口

- `GET /kuu-points/summary.json`：自己的等级、经验、鲸币和今日任务
- `POST /kuu-points/tasks/checkin.json`：签到
- `GET /kuu-shop.json`：鲸币商城页的内容（概况 + 商品）
- `GET /kuu-points/entries.json?page=0`：自己的明细，每页 20 条
- `POST /kuu-points/items/:id/redeem.json`、`PUT / DELETE /kuu-points/items/:id/equip.json`：兑换、佩戴、取下
- `POST /kuu-points/tasks/share.json`：转发（主题的分享菜单在复制链接、保存 / 复制分享图成功后调用）。
  需要登录；每天只奖励一次，重复调用也返回 200，`rewarded` 是 `false`

## 头像装饰图片规格

头像框和饰品用同一种规格，都是叠在头像上的图片：

- **透明背景 PNG，正方形 300×300 px**（想更清楚可以做 600×600，比例不变）。文件尽量小于 200KB
- **头像在正中间，直径 200 px 的圆**（占宽度的 2/3）。图片比头像大一圈，四边各多出 50 px
- **头像框**：画在头像外面的一圈（离中心 100–150 px），可以往里压到头像边缘 10 px 左右；中间直径 180 px 的圆里要完全透明，不然会挡住头像
- **饰品**：画在想放的位置（比如右上角、头顶），其他地方都透明。饰品叠在头像框上面
- 头像在不同地方大小不同（帖子里 45 px、用户卡片和个人主页约 120 px），图片按比例缩放，细线条在小头像上会看不清，建议线条不细于 8 px（300×300 时）
- 测试用的 3 张图在 `lib/discourse_kuu_points/demo_items/`，可以照着看（`bin/rake kuu_points:demo_items` 上架）
